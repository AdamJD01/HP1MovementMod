Mod created by AdamJD.

This is a mod that improves HP1 movement, the camera and climbing.
You can also skip spell learning by holding down the spacebar during the start of the spell learning cutscene. 

How to play:
1. Make a backup of the original retail packages in the HP1 system folder
2. Copy and paste my packages into the HP1 system folder
3. You're all set to go. Have fun!
